# Alexandria Alpha Release 🏛️

We are proud to announce the first functional alpha of **Alexandria**, the decentralized library for the preservation of human knowledge.

> **Warning**: This is Alpha software. Do not use for mission-critical storage yet.

## What is it?
Alexandria is a local-first, peer-to-peer library application. It allows you to:
1. **Archive**: Permanently store books, papers, and datasets on IPFS.
2. **Curate**: Organize content into trusted collections without central gatekeepers.
3. **Preserve**: Automatically detect and rescue "Endangered" content that is disappearing from the network.

## Key Features in Alpha
- **The Veil**: Anonymous routing via Tor (Settings > Security).
- **The Wrapper**: Client-side AES-256 encryption.
- **The Ledger**: A local reputation chain proving your contributions.
- **Biometric Keys**: Secure identity management using your device's Secure Enclave.

## How to Help
We need **Librarians** to test the network.
1. Install the app.
2. Add a copyright-free book or paper.
3. Check if it appears in the "Recent" feed.
4. Try to access it from another device (or via a public IPFS gateway).

## Known Issues
- Network discovery may take up to 30 seconds on first launch.
- Large files (>100MB) may stall on mobile data connections.
